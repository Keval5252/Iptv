Operation Guide: KODI (Version 17+)

How to configure PVR IPTV Simple Client on Kodi Krypton 17+

1. Open Kodi and select TV

2. Select "Enter add-on browser"

3. Select "PVR IPTV Simple Client"

4. Select "Configure"

5. Select "General"

6. For remote M3U URL: Set location to "Remote path"

7. Select "M3U Playlist URL"

8. Enter your M3U URL and select "OK"

9. For local M3U file: Set location to "Local path"

10. Select "M3U Playlist URL"

11. Navigate to your local file and select it

12. Click "OK"

13. Wait for channel loading notification

14. Return to home screen and select "TV"

15. Your channel list should appear
